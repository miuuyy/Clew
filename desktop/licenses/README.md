# Supplemental dependency notices

The installed npm packages below omit a standalone license file. Their notices
are shipped alongside the notices collected from installed dependencies.

| Package | Notice source |
| --- | --- |
| `remark-math@6.0.0`, `rehype-katex@7.0.1` | `remarkjs/remark-math` repository license at commit `76c14978ff6805011b8c56727c54104a511b9055` |

The collector checks these exact versions. Updating a dependency requires
reviewing its notice again. Electron's own `LICENSE` and `LICENSES.chromium.html`
remain in the native distribution. Python notices include the Python runtime
license and installed native build-environment package notices.

Bundled Manrope and JetBrains Mono fonts retain their upstream SIL Open Font
License notices under `frontend/public/fonts` and the release's font notices.
