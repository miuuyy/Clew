# Clew 使用指南

[English](USAGE_GUIDE.md) · [简体中文](USAGE_GUIDE.zh-CN.md) · [返回 README](../README.zh-CN.md)

## 开始使用

按照[桌面安装指南](DESKTOP.zh-CN.md)安装 Clew。在登录页底部选择 **简体中文**，再使用 ChatGPT 登录。登录后，可从 **设置 → 助手与工作区 → 界面语言** 切换语言。

选择 **创建图谱**，填写标题和学科。**图谱语言**决定助手在这个图谱中使用的学习语言。新图谱默认使用当前界面语言，也可以在创建时单独选择。切换界面语言时，已有图谱和对话会保留原文。

## 规划学习路径

在助手对话里说明你已经掌握的知识和想达成的目标。例如：

> 我会用 Python 处理表格数据，也学过基础概率。请为我规划一条用 scikit-learn 做分类项目的学习路径。我每周可以花 4 小时。

助手可以提出新增主题和先修关系。打开 **查看拟议变更**，检查主题、时间估计和资料，再选择 **将提案应用到图谱**。可以随时在 **设置 → 快照** 中恢复先前的工作区状态。

已有主题清单时，也可以选择 **整理主题** 并粘贴 Markdown。为每个主题写一小段介绍，如有可靠的预计时长或学习资料，也可以附上。例如：

```text
- 网络基础
  学习 IP、端口、路由、DNS 和数据包传输。
  预计时长：2 小时。
  练习：用 Wireshark 查看一次 DNS 查询。
```

## 学习、测验和进度

- 在图谱中点选一个主题，查看简介、先修学习路径、资源和笔记。
- 选择 **学习「主题」** 可以打开该主题的对话。工作区仍保留可用于整体规划的通用对话。
- 完成先修主题后，选择 **开始主题测验**。达到通过要求后，Clew 会记录完成状态。
- 可以在设置中调整测验题数和通过要求。关闭主题测验后，使用 **标记为已完成**。
- 使用图谱上方的切换按钮选择 2D 或 3D 视图。可以在图谱中拖动主题，按需保存自定义布局。

## 导入和导出

- 在 **创建图谱** 中选择 **从文件导入**，打开 Clew 图谱包并决定是否保留学习进度。
- 选择 **从 Obsidian 导入**，可将仓库中的 Markdown 笔记和链接转换为图谱。导入前可以查看预览和验证结果。
- 在图谱的导出菜单中选择 **Clew 图谱包** 或 **Obsidian 文件夹**。详细的关系标注、导入设置和导出内容见 [Obsidian 导入和导出](OBSIDIAN.zh-CN.md)。

Clew 在本机保存图谱、学习进度和对话。可以从 **帮助 → 打开数据文件夹** 找到数据。在 ChatGPT 的 **设置 → 用量 → 应用限额** 中，可以调整 Clew 可使用的订阅额度。
