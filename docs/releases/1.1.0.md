# Clew 1.1.0

Clew now supports Simplified Chinese on Windows, macOS, and Linux. Choose **简体中文** on the sign-in screen or under **Settings → Assistant and workspace → Interface language**. Clew remembers your choice on this device.

- Simplified Chinese covers the workspace, graph controls, assistant, quizzes, Obsidian dialogs, and desktop menus.
- New graphs default to the interface language. Each graph has its own language for learning with the assistant. Chinese graphs also get Chinese headings when exported to Obsidian.
- ChatGPT sign-in handles repeated browser callbacks. Unanswered quiz cards stay available after an interrupted reply.
- Reopening chat starts at the latest message. A topic window you dragged stays in place as you select other topics.
- Completion quizzes honor the configured question count and passing score. Clew rejects proposals that introduce prerequisite cycles.

## Downloads

| Platform | Installers |
| --- | --- |
| Windows x64 | Installer |
| macOS 13+ | Apple Silicon and Intel, DMG or ZIP |
| Linux x64 and arm64 | AppImage or Debian package |

Linux needs Secret Service and D-Bus for sign-in. AppImage also needs FUSE 2 and unprivileged user namespaces. Choose the Debian package on distributions that restrict AppImage. macOS uses ad-hoc signing. The OS may warn about publisher identity on macOS and Windows.

## Existing workspaces

Use **Help → Check for Updates** to open the download page, then close Clew and install the new package. Your local graphs, snapshots, and conversations are retained.

## 简体中文

Clew 现已支持简体中文。在登录页底部选择 **简体中文**，或在 **设置 → 助手与工作区 → 界面语言** 中切换。语言选项会保存在本机。新图谱默认使用当前界面语言，也可单独设置图谱的学习语言。可以直接安装新版本，本机的图谱、快照和对话会保留。
