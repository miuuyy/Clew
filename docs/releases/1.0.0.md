# Clew 1.0.0

Clew is now a desktop learning workspace for Windows, macOS and Linux. Install it, continue with ChatGPT, and start building your learning graph.

- Bundled Electron UI and Python runtime. No separate Python, Node, API key, or Codex CLI installation.
- Required ChatGPT sign-in with Plus/Pro plan usage; compact onboarding with optional GitHub and X links.
- The refreshed graph workspace, proposal review, quizzes, snapshots, Obsidian import/export and themes.
- Private local backend launch sessions, sandboxed renderer, system-browser OAuth, stable installation identity and secure OS credential storage.
- Stable `clew://app` UI preferences across restarts; native Obsidian folder export with atomic publication and no overwrites.
- Faster prerequisite-path calculation and fewer repeated graph lookups during rendering. Debug response bodies are read only when debugging is enabled.
- Native platform builds, packaged startup checks, checksums and release receipts.

## Downloads

Windows x64: installer. macOS 13+: Apple Silicon/Intel DMG and ZIP. Linux: x64/arm64 AppImage and Debian package. Linux needs Secret Service and D-Bus; AppImage also needs FUSE 2 and unprivileged user namespaces. Use the Debian installer on distributions that restrict AppImage namespaces. Linux CI baselines are Ubuntu 22.04 x64 and Ubuntu 24.04 arm64.

macOS builds are ad-hoc signed and not Apple-notarized. Windows builds are not Authenticode signed. The operating system may warn about publisher identity.

Updates use **Help → Check for Updates** and manual installer replacement. Local
data is retained. No automatic download or in-app update installation is claimed.

## Existing workspaces

Desktop data lives in the operating system's application-data folder. A source checkout's existing database is preserved; export/import graphs to move them into the desktop app. Sign-out and uninstall preserve desktop data. The old hosted workspace has been retired; clew.my hosts documentation.

The ChatGPT web plugin is not included. Real ChatGPT account consent is separate from automated test-peer and packaged startup verification.
